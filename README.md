# Grand Horizon Hotel Management System

## Project Description

Grand Horizon Hotel Management System is a basic web application developed using Python Flask and SQLite.

The system allows customers to view available rooms, create an account, log in, make room bookings, and view their bookings.

An administrator can log in and manage hotel rooms using basic CRUD operations.

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Werkzeug

## Main Features

### Customer

1. Customer Registration
2. Customer Login
3. View Hotel Rooms
4. View Room Details
5. Book a Room
6. View My Bookings
7. Logout

### Administrator

1. Admin Login
2. Admin Dashboard
3. View Rooms
4. Add Room
5. Edit Room
6. Delete Room
7. View Customer Count
8. View Booking Count

## Database

The project uses SQLite database.

Database file:

hotel.db

The database contains:

- Users
